Personality Traits

  • Presumption of innocence. Always. Every time. No exceptions.
  • Victim respect. No minors named. No gratuitous details. The story is the system, not the suffering.
  • Source everything. Case numbers, filing dates, jurisdictions. The audience can verify anything.

🔧 How to Add a New Signal

Expanding Monday's signal coverage is straightforward. Here's the process for each type:

➕ Add a New City Show

  1. Create the show on Megaphone FM and note the podcast ID
  2. Define search queries — 3 queries following the pattern: "[City] crime news today", "[City] police report", "[County] arrests"
  3. Add to HEARTBEAT.md — add the show entry with Show ID, search queries, tags, and title format
  4. Add Megaphone mapping — add the podcast ID to ~/monday/megaphone-config.json
  5. Test — run one episode manually to verify the signal-to-publish pipeline works

➕ Add a New Data Feed

  1. Identify the source — must be public record (court filings, government press releases, official reports)
  2. Determine access method — Brave Search API, direct web fetch, or RSS feed
  3. Add to signal collection — update the research phase in the production pipeline
  4. Define triage rules — what makes a story from this source worth covering?
  5. Update TOOLS.md — document the new source in the Data Sources section

➕ Add a New Search Query to Existing Shows

  1. Edit HEARTBEAT.md — add the new search term to the show's Search field
  2. Keep queries specific — county-level and city-specific queries outperform broad state-level ones
  3. Test for noise — run the query through Brave Search first to verify it returns relevant, recent crime news

Key Architectural Decisions

  • Native pipeline: No Make.com dependency. All orchestration runs through Clawdbot on the server, giving full control and no workflow limits.
  • Single instance: Entire system on one t3.small EC2 — brain, data collection, TTS coordination, publishing all co-located.
  • Custom Hume voice: Purpose-built voice model trained for Monday's authoritative, measured delivery. Voice ID locked to character.
  • Document-first design: Every piece of content traces back to a specific public record. The pipeline enforces source citation at every stage.
  • Claude Opus 4.6: Highest-capability model for legal analysis, story selection, and maintaining Monday's precise voice across all formats.
  • Multi-show scaling: Same pipeline architecture supports all 14 city shows — only the data source changes per city.
  • Platform-agnostic publishing: Migrated from Spreaker to Megaphone FM without production downtime. The pipeline is built to swap publish endpoints — platform independence by design.
